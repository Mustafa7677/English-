# 4090: THE CURSED CITY — 3D Brainrot Horror

Бірінші жақтан басқарылатын, браузерде іске қосылатын 3D хоррор-комедия.
Барлық модельдер, текстуралар және дыбыстар кодпен (procedural) жасалған — сыртқы ассеттер жоқ.

## Іске қосу

**Орнатусыз ойнау:** `play.html` — бүкіл ойын бір файлда. GitHub Pages қосылса, тікелей ашылады:
`https://mustafa7677.github.io/English-/cursed-city-4090/play.html`


Node.js 18+ керек.

```bash
cd cursed-city-4090
npm install
npm run dev        # http://localhost:5173 ашыңыз
```

Production нұсқасы:

```bash
npm run build      # dist/ папкасына жинайды
npm run preview    # жиналған нұсқаны тексеру
```

Кітапханалар: `three@0.170.0`, `vite@5.4.11` (нұсқалары `package.json` ішінде бекітілген).

Debug: `http://localhost:5173/?god` — ойыншы өлмейді. Консольде `G` объектісі қолжетімді.

## Жасалған функционал (жұмыс істейді)

**Негізгі жүйелер**
- First-person controller: жүру/жүгіру/еңкею/секіру, stamina, денсаулық (баяу қалпына келеді), қорқыныш индикаторы.
- Pointer lock, ESC → пауза, Resume / Restart / Settings.
- Коллизия (AABB vs цилиндр), NPC-лер кедергіні айналып өтеді, бір-бірімен соқтығысып құлайды.
- Ragdoll-имитация: баллистикалық дене + аударылу (inverted pendulum) + «былқылдақ» қол-аяқ, отқа тұру анимациясы.
- NPC көру (FOV + line-of-sight) және есту (жүгіргенде шу көп).
- Скрипт жүйесі (`function*` генераторлар) — әр сахна нақты, кезекті әрекеттер.
- Кездейсоқ оқиғалар генераторы: әр 30–60 секунд сайын ойыншының алдында бір гэг, бір уақытта басталып кетпейді.
- 3D позициялық дыбыс (HRTF), субтитрлер + браузердің Speech API арқылы дауыс.
- Жиналатын заттар: кірпіштер (R — лақтыру), фонарь батареялары.
- Quest жүйесі, Game Over, Win, Restart.
- Баптаулар: графика сапасы (Low/Medium/High: render scale, көлеңкелер, шам жарықтарының саны, тұман), PS1 режимі (пиксельдеу + vertex wobble), тышқан сезімталдығы, дыбыс, хоррор басталу уақыты, FPS көрсету.
- Оңтайландыру: статикалық матрицалар қатырылған, геометрия/материал кэші, тек жақын шамдарға нақты жарық (light pool), алыс NPC-лерге анимация LOD.

**Сахналар**
1. 03:33 оянатын intro, «WELCOME TO 4090 CITY», айқайлап жүгірген адам → құлайды → 5 сек жатады → «I'M ALIVE!» → бағанаға соғылады.
2. Адам сүйреген арба, үстінде костюм мен қалпақ киген, қамшысы бар жылқы. Адам сүрінеді, жылқы ұшып түседі, 3 сек қарап тұрады, екі аяқтап қуады, ұстаса — скример. Сосын арбасына қайтады.
3. NVIDIA ғимараты: есік ашылады, Mei RTX 4090-ты құшақтап қашады, «RETURN MY RTX 4090!» роботы. Mei құлайды, видеокарта ұшып бейтаныс адамның басына тиеді. Робот жақындағанда FPS 60→30→10, glitch, «GPU OVERHEATING», қызыл аварийлық жарық, нақты пиксельдену. Картаны өзің аласың немесе Mei-ге көмектесесің; кірпішпен роботты есеңгіретуге болады.
4. Қорқынышты балабақша (ішінде балалар жоқ): қызыл жарық, бос бөлмелер, өздігінен жылжитын орындықтар, бұрылатын манекендер, сарт етіп жабылатын есіктер, шексіз дәліз, Caretaker елесі (қарап тұрады → жарық өшеді → жоғалады → аяқ дыбысы → артыңда тұрады), кенет пайда болатын ересек NPC.
5. 15 күлкілі NPC оқиғасы (6, 7, 8, 11, 12 — орынға байланған; қалғаны кездейсоқ генератордан).
6. Таксидің басы жоқ манекен жүргізушісі: есік өзі ашылады, бірінші бұрылыста қоқыс жәшігіне соғылады, жүргізуші ұшып шығып, қайта отырады.
7. Дәретхана монстры: бос унитаз → бұрылсаң → «WHO STOLE MY WIFI?!» → кішкентай аяқпен қуады → тайып құлап қабырғаға соғылады.
8. Қате жұмыс істейтін NPC: қалқиды, 180° бұрылады, T-pose, қабырғаға жүре береді, алдыңа телепорттап «YOU ARE NOT SUPPOSED TO BE HERE.» деп glitch болып жоғалады.
9. Хоррорға ауысу (әдепкі 11 мин, баптауда өзгереді, немесе RTX алғанда): алыс NPC-лер қатады → дыбыс жоғалады → шамдар бір-бірден өшеді → бұрылсаң бәрі артыңда қарап тұр → «THEY KNOW YOU HAVE THE 4090.» → бәрі қуады, құлайды, қайта тұрады → аспанда алып жылқы басы «WHERE IS MY CART?!».
10. Финал: аспан жасыл, ғимараттар дірілдейді, арба аспанда ұшады, робот алып боссқа айналады, гравитация уақытша бұзылады, кей NPC қалқиды. 3 генератор (жанармай бекеті, жасырын жертөле, NVIDIA артында) → қақпа ашылады → катсцена: арба мен жылқы алдыңнан тағы өтеді → «TO BE CONTINUED... RTX 5090».
- Сіздің идея: **Buddy** — досың болып ереді, монстр көрсе алдыңа жүгіреді, бірақ үнемі сүрініп құлайды да, ұйықтап тұрған манекен-монстрларды оятып жібереді. Соңына дейін бірге.

## 3-тарау: түнгі супермаркет және жаңа механикалар

- **Ішіне кіруге болатын супермаркет.** Есіктің жазуы «PUSH», ашу үшін итересің. Ішінде сөрелер мен тауарлар, жыпылықтайтын люминесцент шамдар, касса бар.
  - Кіргенде есік артыңнан жабылып, PA: «Дүкен жабық. Ішінде қалыңыз. Мәңгі.»
  - «Price check on aisle four» кезінде шам 3 рет сөнеді. Әр жолы манекен-сатып алушылар саған жақындай түседі. Үшінші жолы айналаңды қоршап тұрады... «Сүт қай жерде екенін білесіз бе? Үш жыл іздеп жүрміз.»
  - Кассир-манекен ештеңе сканерлеп тұрмайды: «Your total is one soul and 99 cents.» Үшінші рет сөйлессең, тегін энергетик береді.
  - Басқа жаққа қарап тұрғанда сауда арбасы саған қарай жылжиды. Ішінде «be my friend» деген жазба бар, содан кейін соңыңнан ереді.
  - Сөрелердің арасымен жүгірсең, тауарлар құлайды: «Clean up on aisle... wherever you are.»
  - Ақырында PA: «Buddy есімді ересек адам адасып, кассаның жанында жылап отыр.»
- **Қоқыс жәшігіне тығылу (E):** монстрлар сені жоғалтады, денсаулық қалпына келеді. Кейде жәшік «OCCUPIED!» болып шығады, кейде біреу басыңа қоқыс қапшығын лақтырады. Хоррор кезінде есікті қағады: «4090 ішінде ме?... жоқ, жай қоқыс екен.»
- **📻 4090 FM:** әр 2–4 минут сайын абсурд радио хабары шығады, мазмұны ойын кезеңіне қарай өзгереді.
- **BRAINROT ENERGY:** 15 секунд бойы жылдамдық +25%, stamina таусылмайды. Қалада 6 банка бар.
- **Өлім себебі:** game over экранында сені не өлтіргені күлкілі түрде жазылады («Defeated by a toilet. It was about the WiFi all along.»).

## 4-тарау: мемдер мен скримерлер

**Мемдік жағдайлар**
- **Log Man:** түнгі 3-те ағаш адам қабырғаны қағады: «KNOCK. KNOCK. KNOCK. ...WAKE UP. IT'S 3:33.» Жақындасаң, денесі қозғалмай тұрып, басы 180° бұрылады. Сосын таяқпен қуады, ақырында құлап: «...кешір, басқа үй екен.»
- **Sneaker Shark:** кроссовка киген үш аяқты акула айнала жүгіреді, жолындағы адамдарды құлатады, алдыңа келіп би билейді.
- **Crocoplane:** қаланың үстінен ұшақ-крокодил ұшып өтіп, резеңке тауықтар тастайды. Тауықтар адамдарды құлатып, «squeak» деп шиқылдайды.
- **Coffin dance:** денсаулығың 35%-дан төмендесе, табыт көтерген 4 адам ерте келіп, айналаңда билейді: «Біз сәл ерте келдік, күте тұрамыз.» Денсаулық қалпына келсе: «...жалған дабыл, кеттік.»
- **🤨 Күдікті көзқарас:** NPC тоқтап, саған қарайды, камера зум жасап, BOOM.
- **Freeze-frame:** біреу құласа, кадр кейде сепия түсінде қатып, «💀💀💀» / «skill issue» деген жазу шығады.

**Жаңа скримерлер**
- Қараңғыда фонарьды қоссаң, кейде алдыңда бетсіз әйел тұрады.
- Ұзақ жүгіріп келе жатып артыңа бұрылсаң, кейде қызыл көзді манекен тұрады. Buddy: «Хоррордың 1-ережесі: ешқашан артыңа қарама.»
- Көшедегі теледидарлар шуылдап тұрады. Жақындасаң, экранда бет пайда болып айқайлайды, сосын «PLEASE STAND BY» шығады.
- Buddy-дің селфиі: ақ жарқыл, «SAY CHEESE!», бетіңе тура жақын келген күлкілі скример.

## 5-тарау: «нағыз ойын» сапасы

- **Графика:** bloom (шамдар, NVIDIA, қызыл терезелер жарқырайды), кинопленка дәні, хроматикалық аберрация, виньетка, түс түзету. Қорқыныш артқан сайын түс кетіп, бұрмалану күшейеді. Хоррор кезінде түс қызылға, финалда жасылға ауысады. Low сапада эффектілер өшеді.
- **Тебу (LMB):** GMod сияқты физикалық комедия. Адамдар ұшып кетеді, хоррор кезінде тебу — қорғанудың негізгі жолы. Заттарды да тебуге болады, ал жақын тұрған унитаз-монстрды тебу оны тайғанатып жібереді. Роботты тепсең, аяғың ауырады.
- **Juice:** соққы кезінде кадр сәл тоқтайды (hit-stop), экран дірілдейді, шаң мен ұшқын бөлшектері шығады.
- **Компас:** экранның жоғарғы жағында, жасыл ◆ келесі мақсатты, ☺ Buddy-ді көрсетеді және қашықтықты жазады.
- **10 қарғысты дискета 💾:** қаланың әр жеріне жасырылған (балабақшада, жертөледе, супермаркетте, аллеяларда). Әрқайсысында лор бар. Барлығын жинасаң, Buddy-дің кепкасы алтынға айналып, ол енді сүрінбейді.
- **Ұпай мен атақ:** өлгенде де, жеңгенде де көрсетіледі. Атақтар: Lost Tourist → Night Walker → Ragdoll Enjoyer → Certified 4090 Survivor → Brainrot Legend → GOD OF 3:33 AM.
- **Үйрету кеңестері:** ойынның алғашқы минутында басқару бойынша кеңестер шығады.

## 6-тарау: шынайы кейіпкерлер, жаңа ғимараттар, белгілі жердегі мемдер

**Кейіпкерлер:** көз (ағы мен қарашығы), қас, мұрын, құлақ, ауыз, сақал, көзілдірік, саусақтар. Киім түрлері: футболка (суреті бар), күртеше, худи (капюшон, баулар), көйлек (түймелер), костюм. Белбеу, табанды аяқ киім, бауы, түрлі шаш үлгілері. Әр дене мүшесі бір мешке біріктірілген, сондықтан ойын баяуламайды. Кейіпкерлерге аздап өз жарығы берілген (PS1 стилі), сондықтан олар қараңғыда да көрінеді.

**🏋️ 4090 GYM** (оңтүстікте, такси тұрағынан әрі):
- Gym Bro: қолдары алып, аяқтары кішкентай. «NEVER SKIP LEG DAY... мен 2016 жылы аяқ күнін өткізіп алдым». Үшінші рет сөйлессең, протеин коктейлін береді: 🗿 **SIGMA MODE**, 30 секунд бойы тебу екі есе күшті.
- Тренажердегі жігіт: «10 жыл жүгіріп келемін, әлі шаршаған жоқпын... МАКСИМАЛДЫ ЖЫЛДАМДЫҚ!» деп, ұшып кетеді. Кадр қатып, «skill issue» жазуы шығады.
- Штанганың астындағы қаңқа: «...spot me, bro? Мен 1998 жылдан бері страховка күтіп отырмын.»
- Кенет шам сөнеді, қараңғыда біреу боксёр қапшығын ұрып жатыр. Шам жанғанда Gym Bro дәл алдыңда тұр: «BOO. ...Gains.»

**🧺 LAUNDRO-MAT** (спортзалдың жанында):
- Кір жуғыш машинаның ішінде айналып жүрген адам: «АШПА! МЕН АЙНАЛДЫРУ ЦИКЛІНДЕМІН!» Ашсаң, басы айналып құлайды.
- Барлық машина бірден іске қосылып, дірілдеп, саған қарай жылжиды... «♪ CYCLE COMPLETE ♪» — ішінен жалғыз көк шұлық түседі.
- Кептіргіштегі шұлық-монстр (скример): «МЕНІҢ ЕКІНШІ ЖАРТЫМ ҚАЙДА?!» Шұлықты әкеліп берсең, олар қайта қосылады 🎉.
- Сауда автоматы: 1-рет бос банка шығарады, 2-рет «OUT OF ORDER. PLEASE SHAKE.», 3-рет шайқасаң, үстіңе құлайды: «you shook it.»

**⛽ Жанармай бекеті:** баға тақтасына қарап жылап тұрған жүргізуші. Баға 4.09 → 40.90 → 4090 болып өзгереді, ол есінен танып құлайды.

**Балабақшаның әткеншегі:** түнде өзі тербеліп тұрады. Жақындасаң, кенет тоқтап, сыбыр: «...my turn.» Сосын Buddy жүгіріп келіп мінеді: «МЕНІҢ БАЛАЛЫҒЫМ БОЛМАҒАН!»

## 7-тарау: орындарға байланған шынайы скримерлер мен мемдер

**3D скример:** үрейлі бет экранға атылып шығады (2D сурет емес). Оған дейін тыныштық орнайды. Скример кезінде бұрмаланған қабатты айқай, қызыл жарқыл, glitch, камераның зумы мен дірілі болады. Соңынан құлақ шыңылдап, жүрек соғысы естіледі. Бұрынғы скримерлердің дыбысы да күшейтілді.

**Скримерлер (әрқайсысы өз орнында, бір реттен):**
- **Балабақша, шығыс жақтағы ортаңғы сынып:** бор тақтасына әріп-әріппен «WHO IS STILL HERE?» деп жазылады, өшіріледі, сосын «TURN AROUND». Бұрылсаң, Caretaker шығады. Тақтада «GOOD NIGHT :)» қалады.
- **Жасырын жертөле:** генераторды қоссаң, шамдар сөніп, фонарь істемей қалады. Құлағыңның түбінен сыбыр естіледі: «жарықты жақпа...». Сосын Crawler шығады.
- **Супермаркет, артқы қабырға:** «STAFF ONLY» есігі. Ашсаң, ішінде қап-қараңғы... Butcher шығады.
- **Аялдама:** «HAVE YOU SEEN ME?» деген постер. Оның көздері сені бақылап тұрады. Жақын келіп қарасаң, ол постерден шығып кетеді, ал постерде «IT IS BEHIND YOU NOW» деген жазу қалады.

**Мемдер (өз орындарында):**
- **NVIDIA алаңы, үлкен RTX батырмасы:** алдымен **RTX OFF** (бәрі LEGO сияқты пиксельге айналады), сосын **RTX ON ✨** (шектен тыс bloom, хор). Buddy: «Өз терімнің тесіктерін көріп тұрмын».
- **Аялдама:** «WAITING FOR THE 3AM BUS» деген жазуы бар қаңқа: «Кестеде 3:00 деп жазылған. Қай жылы екенін жазбаған». Автобус келгенде: «АҚЫРЫ!! 50 ЖЫЛ!!» деп сүйек-сүйегіне ыдырап кетеді.
- **Супермаркеттің алды:** тасталған сауда арбасы. Орнына қайтарсаң, аспаннан жарық түсіп, хор айтады, «+1000 KARMA».

## 8-тарау: босс, музыка, ауа райы, жалған скримерлер, карта

- **Босс-шайқас (финал):** алып NVIDIA роботының 100 HP-і бар, денсаулық жолағы экранда көрінеді. Кірпішпен стан жасап, сосын **тебу** керек (SIGMA MODE кезінде екі есе күшті).
  - 2-фаза: саған видеокарталар лақтырады.
  - 3-фаза: «FPS: 1» — уақыт баяулайды.
  - Жеңгенде робот құлап, **GOLDEN 4090** түседі (+5000 ұпай). Финалда қалада қосымша кірпіш үйінділері пайда болады.
- **Динамикалық музыка:** тыныш эмбиент, монстр жақындағанда барабан мен бас, хоррорда үрейлі қабат, финалда арпеджио. Сахналар кезінде музыка өшеді.
- **Жаңбыр мен найзағай:** әр 4–6 минут сайын жаңбыр жауады. Найзағай жарқылдаған сәтте алыстағы үйдің үстінде немесе көшеде 12 метрлік қара силуэт сені қарап тұрады, тек сол сәтте ғана көрінеді.
- **Жалған скримерлер:** артыңнан жақындаған аяқ дыбыстары, телефонға «turn around» деген хабар, сыбыр, фонарьдың сөнуі, қабырғаны қағу... ештеңе болмайды. Бірақ 30% жағдайда нағыз скример 10–15 секундтан кейін, сен босаңсығанда келеді.
- **Карта (M):** көрнекті орындар, генераторлар (қызыл/жасыл), қауіптер, мақсат ◆, Buddy және сенің бағытың.
- **Қиындық деңгейі:** Easy (зақым жартылай) / Normal / Nightmare (зақым 1.6x, қорқыныш тезірек өседі).
- **Сақталатын прогресс:** жетістіктер мен ең жақсы ұпай браузерде сақталады, мәзірде көрсетіледі.
