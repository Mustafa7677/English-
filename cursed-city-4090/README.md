# 4090: THE CURSED CITY — 3D Brainrot Horror

Бірінші жақтан басқарылатын, браузерде іске қосылатын 3D хоррор-комедия.
Барлық модельдер, текстуралар және дыбыстар кодпен (procedural) жасалған — сыртқы ассеттер жоқ.

## Іске қосу

**Орнатусыз ойнау (браузерде):** https://raw.githack.com/Mustafa7677/English-/main/index.html
(бүкіл ойын бір файлда: түбірдегі `index.html` және `cursed-city-4090/play.html`).

Екі карта — екі бөлек ойын, әрқайсысының өз сілтемесі бар:
- 4090 CITY: `index.html?map=city`
- METRO 404: `index.html?map=metro`
- Карта таңдау: `index.html?maps`


Node.js 18+ керек.

```bash
cd cursed-city-4090
npm install
npm run dev        # http://localhost:5173 ашыңыз
```

Production нұсқасы:

```bash
npm run build      # dist/ папкасына жинайды
npm run preview    # жиналған нұсқаны тексеру
```

Кітапханалар: `three@0.170.0`, `vite@5.4.11` (нұсқалары `package.json` ішінде бекітілген).

Debug: `http://localhost:5173/?god` — ойыншы өлмейді. Консольде `G` объектісі қолжетімді.

## Жасалған функционал (жұмыс істейді)

**Негізгі жүйелер**
- First-person controller: жүру/жүгіру/еңкею/секіру, stamina, денсаулық (баяу қалпына келеді), қорқыныш индикаторы.
- Pointer lock, ESC → пауза, Resume / Restart / Settings.
- Коллизия (AABB vs цилиндр), NPC-лер кедергіні айналып өтеді, бір-бірімен соқтығысып құлайды.
- Ragdoll-имитация: баллистикалық дене + аударылу (inverted pendulum) + «былқылдақ» қол-аяқ, отқа тұру анимациясы.
- NPC көру (FOV + line-of-sight) және есту (жүгіргенде шу көп).
- Скрипт жүйесі (`function*` генераторлар) — әр сахна нақты, кезекті әрекеттер.
- Кездейсоқ оқиғалар генераторы: әр 30–60 секунд сайын ойыншының алдында бір гэг, бір уақытта басталып кетпейді.
- 3D позициялық дыбыс (HRTF), субтитрлер + браузердің Speech API арқылы дауыс.
- Жиналатын заттар: кірпіштер (R — лақтыру), фонарь батареялары.
- Quest жүйесі, Game Over, Win, Restart.
- Баптаулар: графика сапасы (Low/Medium/High: render scale, көлеңкелер, шам жарықтарының саны, тұман), PS1 режимі (пиксельдеу + vertex wobble), тышқан сезімталдығы, дыбыс, хоррор басталу уақыты, FPS көрсету.
- Оңтайландыру: статикалық матрицалар қатырылған, геометрия/материал кэші, тек жақын шамдарға нақты жарық (light pool), алыс NPC-лерге анимация LOD.

**Сахналар**
1. 03:33 оянатын intro, «WELCOME TO 4090 CITY», айқайлап жүгірген адам → құлайды → 5 сек жатады → «I'M ALIVE!» → бағанаға соғылады.
2. Адам сүйреген арба, үстінде костюм мен қалпақ киген, қамшысы бар жылқы. Адам сүрінеді, жылқы ұшып түседі, 3 сек қарап тұрады, екі аяқтап қуады, ұстаса — скример. Сосын арбасына қайтады.
3. NVIDIA ғимараты: есік ашылады, Mei RTX 4090-ты құшақтап қашады, «RETURN MY RTX 4090!» роботы. Mei құлайды, видеокарта ұшып бейтаныс адамның басына тиеді. Робот жақындағанда FPS 60→30→10, glitch, «GPU OVERHEATING», қызыл аварийлық жарық, нақты пиксельдену. Картаны өзің аласың немесе Mei-ге көмектесесің; кірпішпен роботты есеңгіретуге болады.
4. Қорқынышты балабақша (ішінде балалар жоқ): қызыл жарық, бос бөлмелер, өздігінен жылжитын орындықтар, бұрылатын манекендер, сарт етіп жабылатын есіктер, шексіз дәліз, Caretaker елесі (қарап тұрады → жарық өшеді → жоғалады → аяқ дыбысы → артыңда тұрады), кенет пайда болатын ересек NPC.
5. 15 күлкілі NPC оқиғасы (6, 7, 8, 11, 12 — орынға байланған; қалғаны кездейсоқ генератордан).
6. Таксидің басы жоқ манекен жүргізушісі: есік өзі ашылады, бірінші бұрылыста қоқыс жәшігіне соғылады, жүргізуші ұшып шығып, қайта отырады.
7. Дәретхана монстры: бос унитаз → бұрылсаң → «WHO STOLE MY WIFI?!» → кішкентай аяқпен қуады → тайып құлап қабырғаға соғылады.
8. Қате жұмыс істейтін NPC: қалқиды, 180° бұрылады, T-pose, қабырғаға жүре береді, алдыңа телепорттап «YOU ARE NOT SUPPOSED TO BE HERE.» деп glitch болып жоғалады.
9. Хоррорға ауысу (әдепкі 11 мин, баптауда өзгереді, немесе RTX алғанда): алыс NPC-лер қатады → дыбыс жоғалады → шамдар бір-бірден өшеді → бұрылсаң бәрі артыңда қарап тұр → «THEY KNOW YOU HAVE THE 4090.» → бәрі қуады, құлайды, қайта тұрады → аспанда алып жылқы басы «WHERE IS MY CART?!».
10. Финал: аспан жасыл, ғимараттар дірілдейді, арба аспанда ұшады, робот алып боссқа айналады, гравитация уақытша бұзылады, кей NPC қалқиды. 3 генератор (жанармай бекеті, жасырын жертөле, NVIDIA артында) → қақпа ашылады → катсцена: арба мен жылқы алдыңнан тағы өтеді → «TO BE CONTINUED... RTX 5090».
- Сіздің идея: **Buddy** — досың болып ереді, монстр көрсе алдыңа жүгіреді, бірақ үнемі сүрініп құлайды да, ұйықтап тұрған манекен-монстрларды оятып жібереді. Соңына дейін бірге.

## 3-тарау: түнгі супермаркет және жаңа механикалар

- **Ішіне кіруге болатын супермаркет.** Есіктің жазуы «PUSH», ашу үшін итересің. Ішінде сөрелер мен тауарлар, жыпылықтайтын люминесцент шамдар, касса бар.
  - Кіргенде есік артыңнан жабылып, PA: «Дүкен жабық. Ішінде қалыңыз. Мәңгі.»
  - «Price check on aisle four» кезінде шам 3 рет сөнеді. Әр жолы манекен-сатып алушылар саған жақындай түседі. Үшінші жолы айналаңды қоршап тұрады... «Сүт қай жерде екенін білесіз бе? Үш жыл іздеп жүрміз.»
  - Кассир-манекен ештеңе сканерлеп тұрмайды: «Your total is one soul and 99 cents.» Үшінші рет сөйлессең, тегін энергетик береді.
  - Басқа жаққа қарап тұрғанда сауда арбасы саған қарай жылжиды. Ішінде «be my friend» деген жазба бар, содан кейін соңыңнан ереді.
  - Сөрелердің арасымен жүгірсең, тауарлар құлайды: «Clean up on aisle... wherever you are.»
  - Ақырында PA: «Buddy есімді ересек адам адасып, кассаның жанында жылап отыр.»
- **Қоқыс жәшігіне тығылу (E):** монстрлар сені жоғалтады, денсаулық қалпына келеді. Кейде жәшік «OCCUPIED!» болып шығады, кейде біреу басыңа қоқыс қапшығын лақтырады. Хоррор кезінде есікті қағады: «4090 ішінде ме?... жоқ, жай қоқыс екен.»
- **📻 4090 FM:** әр 2–4 минут сайын абсурд радио хабары шығады, мазмұны ойын кезеңіне қарай өзгереді.
- **BRAINROT ENERGY:** 15 секунд бойы жылдамдық +25%, stamina таусылмайды. Қалада 6 банка бар.
- **Өлім себебі:** game over экранында сені не өлтіргені күлкілі түрде жазылады («Defeated by a toilet. It was about the WiFi all along.»).

## 4-тарау: мемдер мен скримерлер

**Мемдік жағдайлар**
- **Log Man:** түнгі 3-те ағаш адам қабырғаны қағады: «KNOCK. KNOCK. KNOCK. ...WAKE UP. IT'S 3:33.» Жақындасаң, денесі қозғалмай тұрып, басы 180° бұрылады. Сосын таяқпен қуады, ақырында құлап: «...кешір, басқа үй екен.»
- **Sneaker Shark:** кроссовка киген үш аяқты акула айнала жүгіреді, жолындағы адамдарды құлатады, алдыңа келіп би билейді.
- **Crocoplane:** қаланың үстінен ұшақ-крокодил ұшып өтіп, резеңке тауықтар тастайды. Тауықтар адамдарды құлатып, «squeak» деп шиқылдайды.
- **Coffin dance:** денсаулығың 35%-дан төмендесе, табыт көтерген 4 адам ерте келіп, айналаңда билейді: «Біз сәл ерте келдік, күте тұрамыз.» Денсаулық қалпына келсе: «...жалған дабыл, кеттік.»
- **🤨 Күдікті көзқарас:** NPC тоқтап, саған қарайды, камера зум жасап, BOOM.
- **Freeze-frame:** біреу құласа, кадр кейде сепия түсінде қатып, «💀💀💀» / «skill issue» деген жазу шығады.

**Жаңа скримерлер**
- Қараңғыда фонарьды қоссаң, кейде алдыңда бетсіз әйел тұрады.
- Ұзақ жүгіріп келе жатып артыңа бұрылсаң, кейде қызыл көзді манекен тұрады. Buddy: «Хоррордың 1-ережесі: ешқашан артыңа қарама.»
- Көшедегі теледидарлар шуылдап тұрады. Жақындасаң, экранда бет пайда болып айқайлайды, сосын «PLEASE STAND BY» шығады.
- Buddy-дің селфиі: ақ жарқыл, «SAY CHEESE!», бетіңе тура жақын келген күлкілі скример.

## 5-тарау: «нағыз ойын» сапасы

- **Графика:** bloom (шамдар, NVIDIA, қызыл терезелер жарқырайды), кинопленка дәні, хроматикалық аберрация, виньетка, түс түзету. Қорқыныш артқан сайын түс кетіп, бұрмалану күшейеді. Хоррор кезінде түс қызылға, финалда жасылға ауысады. Low сапада эффектілер өшеді.

Кейіпкерлерге аздап өз жарығы берілген (PS1 стилі), сондықтан олар қараңғыда да көрінеді.

## 7-тарау: орындарға байланған шынайы скримерлер мен мемдер

**3D скример:** үрейлі бет экранға атылып шығады (2D сурет емес). Оған дейін тыныштық орнайды. Скример кезінде бұрмаланған қабатты айқай, қызыл жарқыл, glitch, камераның зумы мен дірілі болады. Соңынан құлақ шыңылдап, жүрек соғысы естіледі. Бұрынғы скримерлердің дыбысы да күшейтілді.

**Скримерлер (әрқайсысы өз орнында, бір реттен):**
- **Балабақша, шығыс жақтағы ортаңғы сынып:** бор тақтасына әріп-әріппен «WHO IS STILL HERE?» деп жазылады, өшіріледі, сосын «TURN AROUND». Бұрылсаң, Caretaker шығады. Тақтада «GOOD NIGHT :)» қалады.
- **Жасырын жертөле:** генераторды қоссаң, шамдар сөніп, фонарь істемей қалады. Құлағыңның түбінен сыбыр естіледі: «жарықты жақпа...». Сосын Crawler шығады.
- **Супермаркет, артқы қабырға:** «STAFF ONLY» есігі. Ашсаң, ішінде қап-қараңғы... Butcher шығады.
- **Аялдама:** «HAVE YOU SEEN ME?» деген постер. Оның көздері сені бақылап тұрады. Жақын келіп қарасаң, ол постерден шығып кетеді, ал постерде «IT IS BEHIND YOU NOW» деген жазу қалады.

**Мемдер (өз орындарында):**
- **NVIDIA алаңы, үлкен RTX батырмасы:** алдымен **RTX OFF** (бәрі LEGO сияқты пиксельге айналады), сосын **RTX ON ✨** (шектен тыс bloom, хор). Buddy: «Өз терімнің тесіктерін көріп тұрмын».
- **Аялдама:** «WAITING FOR THE 3AM BUS» деген жазуы бар қаңқа: «Кестеде 3:00 деп жазылған. Қай жылы екенін жазбаған». Автобус келгенде: «АҚЫРЫ!! 50 ЖЫЛ!!» деп сүйек-сүйегіне ыдырап кетеді.

- **Босс-шайқас (финал):** алып NVIDIA роботының 100 HP-і бар, денсаулық жолағы экранда көрінеді. Кірпішпен стан жасап, сосын **тебу** керек (SIGMA MODE кезінде екі есе күшті).

## 9-тарау: бәрі белгілі жерде + рөлдер ауысқан мемдер

- **Белгілі жерлер:** бұрын кездейсоқ гэгтер ойыншының алдынан кез келген жерде шығатын. Енді әрқайсысының **өз орны бар** (18 орын). Картада (M) олар сары нүктемен белгіленген. Жалған скримерлер де белгілі аллеяларда, таксофонның жанында және әткеншектің қасында болады. Фонарь жарығындағы бет тек қараңғы аллеяларда шығады, «артыңа қарама» манекені тек қақпаға апаратын жолда тұрады, Crocoplane әрқашан басты көшенің үстімен ұшады.
- **Buddy жуасытылды:** сирек сүрінеді (әр 2,5–3,5 минут сайын), монстрларды өте сирек оятады, құлағанда айқайламайды, аз сөйлейді, селфи-скримерін енді жасамайды.
- **Жылқы адамды айдап жүр:** арба енді қаланың ортасындағы басты қиылыс арқылы жүреді, ойын басталғанда бірден көзге түседі. Жылқы: «FASTER, HUMAN!», «Солға! СОЛҒА! Басқа солға!»; адам: «...мен экономика мамандығын бітіргенмін...»
- **Ит адамды бау арқылы жетектейді** (оңтүстік көше, такси тұрағының жанында): «Who's a good boy? YOU are, Kevin.» Кевин шам бағаналарын иіскейді.
- **Алып көгершін адамды тамақтандырады** (супермаркеттің алдында): нан үгінділерін шашады. «Coo. Eat, human. Grow strong.»
- **Мысық-бастық** (кір жуатын орынның алдында): «Meow.» (Сен жұмыстан шығарылдың.) Сосын қызметкердің кофесін үстелден итеріп түсіреді.

## Балабақша қайда?
Бастапқы нүктеден алға қарай (солтүстікке) бірінші қиылысқа дейін жүріп, солға (батысқа) бұрыл. Қызыл терезелі, «KINDERGARTEN» деген жазуы бар ғимарат оң жақта тұр. Кіреберісі қиылысқа қараған жағында, есікті E-мен ашасың. Картада (M) «KINDERGARTEN» деп белгіленген.

## 10-тарау: НЕЖДАНЧИКТЕР

Ережелері: алдын ала тыныштық та, ескерту де болмайды. Скример күлкілі немесе қарапайым сәттің ортасында шығады, кейде «бітті» деп босаңсыған кезде екінші рет келеді, кейде мәзірдің ішінде болады. Скример беттері енді бөліктерден құралған бас емес, детальды салынған үрейлі бет: қара көз ұялары, қара «көз жастары», жыртылған ұзын ауыз, тістер, тамырлар. Екі кадр бір-бірімен ауысып, glitch-пен жыпылықтайды.

1. **Мысық-бастық:** әзілден кейін «🏆 SECRET FOUND — жақынырақ қара» деген хабар шығады... сосын айқайлайды.
2. **Такси:** апаттан кейін тыныш келе жатқанда, бір нәрсе терезені сыртынан ұрады.
3. **Биші:** екінші рет саған жүгіріп келгенде тоқтамайды.
4. **Кір жуатын орын:** 4-машинаны «тексер»... әйнекке бет тығылып тұр.
5. **Сауда арбасы:** біраз уақыт ерген соң артқа қарасаң, ішінде біреу отыр.
6. **Аялдама:** елес автобус кеткенде, бір жолаушы сенің артыңда қалып қойған.
7. **Жертөле (қос соққы):** Crawler-ден кейін баспалдақпен жоғары шықтың, құтылдым дедің... ол да сенімен бірге шықты.
8. **Карта (M):** картада «?» белгісі бар қызыл фигура сенің бағытыңа қарай жылжып келеді. Жеткен сәтте...
9. **Пауза мәзірі:** мәзірдің артында бір бет баяу пайда болады. RESUME басқанда...

## 14-тарау: СКРИМЕР 2.0 және қорқыныш режиссері

**Скримердің әр бөлігі қайта жасалды:**
- **Сублиминал кадр:** бет алдымен бір кадрға жарқ етеді де жоғалады, сосын шын скример келеді.
- **Қолдар:** экранның екі шетінен ұзын саусақты, қара тырнақты бозғылт қолдар созылады.
- **Бет:** экранға атылып келеді, жағы созылады, кадрлар арасында бұрмаланып жыпылықтайды.
- **Кадрдың өзі бұзылады:** хроматикалық ажырау, түс кетеді, камера қисаяды.
- **Дыбыс:** қабатты бұрмаланған айқай, соңынан құлақтың шыңылдауы мен жиілеген жүрек соғысы.
- **Қорқыныш режиссері:** әр скримерден кейін 40 секунд «тынығу» болады. Жаңа скример алдында біртіндеп дайындық басталады: денемен сезілетін **инфрадыбыс**, **кері ойнатылған сыбыр**, айналадағы шамдар жыпылықтап, музыка үрейлі қабатқа ауысады.
- **Скример қарқыны** (баптауда): Mild (тыныш, жарқыл аз) / Normal / Extreme (қаттырақ, ұзағырақ, сублиминал кадрлар жиі).
- **Death cam:** өлгенде камера жерге құлайды, ал қала өмірін жалғастыра береді.

**Жаңа скример-механикалар (белгілі жерлерде):**
- **Бетсіз жүгіруші** (қақпаға баратын қараңғы жол, шамдары сөнген). Ұзын бозғылт фигура жолдың ортасында тұрады. Оған фонарь түсірсең немесе жақындасаң, айқайлап, сенен жылдам жүгіреді. **Жарық — қауіпсіздік:** жанып тұрған шамның астына жетсең, ол жарықтың шетінде тоқтап, айқайлайды да, қараңғыға кетеді.
- **Қараңғыдағы қолдар** (жасырын жертөле). Фонарьды өшіріп 4 секунд тұрсаң, экранның шетінен қолдар созыла бастайды. Фонарьды жақсаң, ысылдап кейін тартылады. Жақпасаң — ұстап алады.
- **Төбе** (балабақша дәлізі, Caretaker-ден кейін). Төбеде алдыңнан бірдеңе жорғалап, тырналап жүр. Жоғары қарасаң, ол тура алдыңа құлап түседі.
- **Сублиминал кадрлар** (қараңғы аллеялар, жертөле, NOCLIP). Көз алдыңда бір кадрға бет жарқ етеді. «Бірдеңе көрдім бе?»

  - **Шығу залы:** ақ түс, жасыл «ШЫҒУ ↑» белгілері, алдағы өткелден жарық түседі.
- **Станция сайын қиындайды.** Терең түскен сайын мем жиірек шығады (50%-дан 78%-ға дейін), монстрлар жылдамырақ жүгіреді (×0.86-дан ×1.16-ға дейін), ескерту уақыты қысқарады, жарық азаяды.
- **Мем-жинақ (📒, J пернесі).** Барлығы 24 мем бар: дәлізде 18 мем-скример және пойызда 6 оқиға. Кездескен әр мем жинаққа түседі және ойындар арасында сақталады. Жаңа мем табылғанда хабарлама шығады. Бәрін жинасаң, «Meme Historian» жетістігін аласың.
- **Финал: эскалатор.** Шығу залынан ұзын эскалатормен жоғары көтерілесің. Қарсы эскалатормен осы ойында кездескен мемдердің бәрі төмен түсіп бара жатады: жылқы қол бұлғайды, «67» тобы билейді, басқалары мем жазылған картон ұстап тұр. Олар өтіп бара жатып саған бұрылып қарайды. **Артыңа қарама:** қарасаң, бәрі тоқтап, саған тесіле қарап қалады. Жоғарыда есіктен ақ жарық түседі.
- **Твист.** Жарыққа кірген сәтте: «📢 Келесі бекет — Райымбек батыр». Сен қайтадан соңғы пойыздасың, қарсыңда сол жылқы отыр: «...қайта келдің бе?»
- **Метроның өз жеңіс және жеңіліс экрандары.** Онда уақыт, ұсталу саны, жеткен станция, aura, осы ойындағы мемдер және мем-жинақ торы көрсетіледі. Өлім себебі ретінде сені ұстаған мем жазылады.

## 20-тарау: METRO 404 — бір ұзын пойыз

Метро енді бір ұзын пойыз. Сен ең соңғы вагонда оянасың да, жүргізушіге жеткенше бүкіл пойызды вагон-вагонмен аралап өтесің. Пойыз 10 вагоннан тұрады, әр вагонның өз мемі бар. Мемдер кездейсоқ емес, әрқайсысы өз орнында тұрады және бәрі міндетті түрде шығады.

| Вагон | Не болады |
|---|---|
| 1. Соңғы вагон | Жылқы-жолаушы газетін түсіреді, шам сөнеді. Жанғанда ешкім жоқ: орындықта ережелер жазылған газет, еденде **билет** жатыр (E). |
| 2. **Ей, дүбәрә!** | Еденде тарақан жүгіреді. Апа «ЕЙ, ДҮБӘРӘ!» деп тапочкасын лақтырады, бірақ тарақан сенің бетіңде отыр екен: тапочка да саған тиеді. Сосын апаның сөмкесінен тарақандар төгіліп, саған қарай жүгіреді: қаш! |
| 3. **Зыпылдаған 25** | Ол өте тез сөйлейді: «Сәлем-бауырым-қалайсың-...-ЖАУАП-БЕР!» Сосын скример. Пойыз Райымбек батыр бекетіне тоқтайды, перронда орындықта Buddy отыр. |
| 4. **Контролер** | Контролер артта отырған Отанбасқа келеді: «Білетіңіз қайда?» — «Менің атым Отанбас.» — «Білетіңіз бар ма?» — «Жоқ.» — «Жүр, түсеміз.» Жібек жолы бекетінде екеуі түсіп қалады. Контролер есікте бұрылып, сенен: «...Ал сіздің білетіңіз?» деп сұрайды. Билетің болса, «Жолыңыз болсын» дейді. Болмаса, «ЖҮР. ТҮСЕМІЗ.» деп қуа жөнеледі. Перронда The Dad??? тұр. |
| 5. **Той** | Той болып жатыр: музыка, келін, күйеу жігіт, асаба, торт. Пойыз кенет тежегенде торт ұшып кетеді. «Сен итердің бе?!», «Үш ай бойы жинаған ақшамыз еді...». Сосын қара мысық шапалақтай бастайды, артынша бүкіл той шапалақтайды. Асаба: «Келесі тост — осы жігітке!» |
| 6. **Kaspi** | Kaspi-ге қате ақша түседі. Пойыз Абай бекетінде тежегенде біреудің несиеге алған телефоны құлап сынады: «24 айға!». Перроннан RTX сатушы кіреді: «Бес мыңға! Оригинал!». Орындықта GTA 6 дискісі жатыр. |
| 7. **Ақсақал** | Апа отырған жігітке: «Қазіргі жастар... ұят жоқ.» Жігіт орнын береді. Ақсақал сені тоқтатады: «Кімнің баласысың? Қай рудансың?... Ә, біздікі екенсің!». Шам жыпылықтайды: «Біздің ру метродан ешқашан шықпайды.» Қаш! |
| 8. **Туннель 404** | Пойыз қараңғы туннельде тоқтайды. «...remember... november...». Әр жарқылда ақ аю саған жақындай түседі. |
| 9. **Рэп-баттл** | Барыс MC рэп айтып тұр. Шексіз бекетте есік ашылғанда Karate Cat ұшып кіреді («ХИИИЯ!»), артынан «67» тобы мінеді. Баттл басталады. Соңында: «Қай ауданнансың? ҰСТА ОНЫ!» |
| 10. **Бас вагон** | Жарнамалардың бәрі бетке айналады. «Келесі бекет... ЖЕР БЕТІ. ЖЕР. БЕТІ.» Артыңнан қараңғылық келеді, ішінен «ОЙЛАШЫ!» деген айқай естіледі. Кабинадағы жүргізуші бұрылып: «Сен кешіктің.» Сосын туннельдің алдынан бір пойыздың соңғы вагоны көрінеді: ол сенің өз пойызың, артқы терезеден жылқы қол бұлғап тұр. |

**Ереже:** алға жүр. **Шам қызарса**, мем скримерге айналады, сондықтан келесі вагонға қаш. Артыңдағы есік жабылады, қуғыншы әрі өте алмайды. Ұсталсаң, сол вагон басынан басталады. Әр сахнаның ортасында келесі вагонның есігі уақытша ашылмайды, сондықтан ешбір мем өтіп кетпейді.

**Пойыз шын жүреді:** терезеден туннель шамдары зулап өтеді, вагон сілкінеді. Әр бекетте пойыз тежеледі, сол бекеттің безендіруімен перрон жақындайды, есіктер ашылады, сосын «Абайлаңыз, есіктер жабылады» деп жабылып, пойыз қайта жүреді.

Пойыздан кейін: шығу залы, эскалатор және «Келесі бекет — Райымбек батыр».

Мем-жинақ енді 24 пойыз мемінен тұрады. Қазақша жолдарды қазақ дауысы оқиды. Ондай дауыс болмаса, орыс дауысы оқиды (ол кирилицаны оқи алады). Ешқайсысы болмаса, тек субтитр шығады.
